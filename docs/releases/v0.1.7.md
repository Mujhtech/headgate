# v0.1.7 release notes

## Structured attempt logs

- Go: `headgate.Logger(ctx)` returns a job-scoped `slog.Logger` with debug, info, warn, and error levels, structured scalar fields, and capture timestamps.
- Rust: `ctx.logger().info("Downloading").field("file_id", "file-123").emit()` records the same structured log format.
- The console displays level badges, timestamps, expandable fields, and per-attempt level filters. Existing plain-text logs remain readable as info entries.
- Go and Rust share a versioned string-entry format without changing the store interfaces or requiring a database migration.
- Updated documentation, runnable progress examples, and the read-only UI demo demonstrate structured logging.

## Fixes and maintenance

- Updated Go dependencies to `pgx` v5.9.2, `go-redis` v9.7.3, and `golang.org/x/text` v0.39.0 to address GO-2026-5004, GO-2025-3540, and GO-2026-5970 respectively.
- Attempt log buffers stop accepting records after the runtime collects them. Plain and structured entries share a bounded budget, with UTF-8-safe truncation.
- Logging tests clean up their fixtures. Retention conformance tests handle unrelated expired jobs, exercise multiple bounded eviction batches, and verify unexpired results survive.
- Refreshed the Go and Rust embedded console assets, including tighter sidebar item spacing.

## Upgrade notes

- The Go SDK and workspace now require Go 1.25 or newer because of the patched dependencies. Use a current patch release of Go. The standalone CLI and UI modules retain their Go 1.24 minimum.
- Upgrade the Headgate Rust crates and Go modules together to v0.1.7. No database migrations are added in this release.
- Logs are saved at attempt acknowledgement, not streamed live. Existing outcome and retention rules still apply.
- Error-level logs do not fail a job. Return an error to change the outcome.
- Logs remain plaintext even when job payload encryption is enabled; avoid logging secrets or sensitive payloads.
- Older consoles display structured entries as encoded text. Use the updated embedded console for the formatted view.
