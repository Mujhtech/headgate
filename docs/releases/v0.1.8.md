# v0.1.8 release notes

## Native Prometheus metrics for Go and Rust

- Added `github.com/mujhtech/headgate/go/headgateprometheus`, a native Prometheus adapter
  for Headgate's existing telemetry interface, and the matching `headgate-prometheus`
  Rust crate.
- Exports lifecycle counters, an attempt-duration histogram, and worker saturation,
  capacity, memory, and restart metrics through an application-owned registry.
- Uses bounded operational labels and deliberately excludes job IDs, fingerprints,
  partitions, payloads, results, errors, and logs.
- Registration collisions return errors; neither adapter uses the global registry or
  starts an HTTP server. See `docs/operations/prometheus.mdx` for setup and PromQL.

## Durable workflow orchestration

- Added durable signals with payload and emitter/source history, relative timers,
  conditions, additive graph grafts, failed-subgraph retry generations, child workflows,
  and workflow inspection APIs in Go and Rust.
- Preserved completed dependency evidence across long-running workflow steps and fixed
  durable event namespacing and Redis event-value persistence.
- Expanded the workflow console with selectable graph nodes, signal and wait detail,
  retry-generation context, and richer timelines.

## Go 1.27 and maintainability

- The Go workspace now requires Go 1.27 and uses current language and standard-library
  idioms across all modules.
- Split the core runtime, control API, workflow module, and PostgreSQL, MySQL, and Redis
  drivers by responsibility without changing their public contracts.
- Added workspace-wide formatting, vet, lint, vulnerability, race, and modernization
  checks, plus deterministic test synchronization and runtime profiling labels.

## Console and correctness fixes

- Added theme and polling preferences, stable queue selection, consistent pagination and
  actions, relative times, improved job sheets, and updated workflow graph rendering.
- Operators can explicitly retry cancelled jobs.
- Fixed translated-page DOM cleanup, root Go workspace selection in CI, and several
  cross-module dependency and generated-asset synchronization issues.

## Upgrade notes

- Upgrade the Headgate Rust crates and Go modules together to v0.1.8.
- Go applications need Go 1.27 or newer.
- This release includes schema migration 13 for durable workflow events. Apply the normal
  Headgate migrations before using signal history and the new workflow inspection data.
- Existing jobs and static workflows remain compatible. The Prometheus adapter is opt-in
  and does not add a dependency to the core Go module.
