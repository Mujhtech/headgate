# v0.1.9 release notes

## Mount-aware embedded console

- The embedded operations console now derives its browser-visible mount path from the
  entry module URL and configures TanStack Router before the initial route load.
- Go `http.StripPrefix`, Rust nested services, and equivalent reverse-proxy setups can
  mount the console below arbitrary paths such as `/admin/headgate` without rendering
  the console's 404 page.
- Client-side navigation, direct deep links, styles, scripts, and public assets remain
  under the selected mount path. Root-mounted consoles continue to work unchanged.

## Packaging and verification

- Added focused mount-path tests and a custom client bootstrap that applies the runtime
  router base path before hydration completes.
- Rebuilt the standalone and Go-embedded console distributions from the same verified
  source bundle.
- Exercised a prefixed Go demo against PostgreSQL, including client navigation and a
  fresh deep-link load with live data.

## Upgrade notes

- Upgrade the Headgate Rust crates and Go modules together to v0.1.9.
- No database migration or control API change is required for this patch release.
- Applications already mounted at `/` require no configuration changes. Applications
  using a prefix should continue stripping or nesting that prefix at the server boundary;
  the console now discovers the corresponding browser path automatically.
